# Standard Laptop Request Flow

## Flow Objective

Create a Catalog Task for approved Standard Laptop Service Requests.

## Process

1. Standard Laptop request is submitted.
2. The request goes through the configured approval process.
3. The flow checks the approval condition.
4. When the request is approved, a Catalog Task is created.
5. The Catalog Task is assigned to the Hardware assignment group.
6. The Hardware team can process the laptop configuration task.

## Assignment Group

Hardware

## Expected Result

An approved Standard Laptop request automatically generates a Catalog Task assigned to the Hardware team.
