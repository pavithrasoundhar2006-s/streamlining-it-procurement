# Streamlining IT Procurement

## Project Overview

This project automates the Standard Laptop request process in ServiceNow.

The automation creates a Catalog Task after the required approval condition is met and assigns the task to the Hardware assignment group.

## Objective

- Automate Catalog Task creation
- Reduce manual task creation
- Improve request processing speed
- Automatically route laptop requests to the Hardware team

## Technology

- ServiceNow
- Flow Designer
- Service Catalog
- Catalog Tasks

## Workflow

Standard Laptop Request
        ↓
Approval Check
        ↓
Approved
        ↓
Create Catalog Task
        ↓
Assignment Group = Hardware
