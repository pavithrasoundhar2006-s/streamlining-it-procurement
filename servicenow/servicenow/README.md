# ServiceNow Implementation

This folder contains the ServiceNow implementation documentation for the Standard Laptop request automation.

## Components

- Standard Laptop Service Catalog Item
- Flow Designer
- Approval Process
- Catalog Task
- Hardware Assignment Group

## Automation

When an approved Standard Laptop request is processed, a Catalog Task is created and assigned to the Hardware assignment group.
