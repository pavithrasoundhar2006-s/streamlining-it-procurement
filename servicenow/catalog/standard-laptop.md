# Standard Laptop Catalog Item

## Purpose

The Standard Laptop catalog item is used to submit a request for a standard company laptop.

## Request Process

1. User submits a Standard Laptop request.
2. The request enters the approval process.
3. After approval, the automation creates a Catalog Task.
4. The task is assigned to the Hardware assignment group.
5. The Hardware team processes the request.

## Automation

The Standard Laptop request is connected to the ServiceNow automation flow.

## Expected Result

A successful request should result in a Catalog Task assigned to:

**Assignment Group:** Hardware
