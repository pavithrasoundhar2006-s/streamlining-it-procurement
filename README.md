# Streamlining IT Procurement

## Project Title

Automating Standard Laptop Requests in ServiceNow

## Project Overview

This project automates the Standard Laptop request process in ServiceNow.

Once a Standard Laptop request reaches the configured approval condition, a Catalog Task is automatically created and assigned to the Hardware assignment group.

## Objective

The main objective of this project is to:

- Automate Catalog Task creation
- Reduce manual task creation
- Improve request processing speed
- Automatically route approved laptop requests
- Ensure tasks are assigned to the Hardware team

## Process Flow

Standard Laptop Request
        ↓
Approval Process
        ↓
Approval Condition
        ↓
Approved
        ↓
Create Catalog Task
        ↓
Assignment Group = Hardware
        ↓
Hardware Team Processes Task

## ServiceNow Components

- Service Catalog
- Standard Laptop Catalog Item
- Flow Designer
- Requested Item
- Catalog Task
- Hardware Assignment Group

## Project Milestones

### Milestone 1: Flow

Create a Flow to automatically create a Catalog Task for approved Standard Laptop requests.

### Milestone 2: Flow Assignment

Configure the Catalog Task assignment to the Hardware assignment group.

### Milestone 3: Service Catalog

Configure and validate the Standard Laptop Service Catalog request.

## Expected Outcome

Approved Standard Laptop requests should automatically generate a Catalog Task and route it to the Hardware assignment group.

## Benefits

- Less manual effort
- Faster processing
- Consistent task assignment
- Improved IT procurement workflow
- Better request tracking
